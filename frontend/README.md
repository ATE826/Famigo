# Famigo — frontend

Интерфейс Famigo на JavaScript/JSX, React 19, React Router 7 и Vite 8 с React Compiler. Стили — CSS Modules и общие CSS-переменные. Данные и действия страниц предоставляет React Context. TypeScript в исходниках не используется.

Документация сверена с кодом **17.11.2026**.

## Запуск для разработки

Для Node.js 22 используйте версию 22.12 или новее; полный диапазон совместимости указан в зависимостях Vite. Из корня репозитория:

```bash
cd frontend
npm ci
npm run dev
```

Адрес: [http://localhost:5173/Famigo/](http://localhost:5173/Famigo/). Базовый путь `/Famigo/` задан в `vite.config.js` и `BrowserRouter`. Vite проксирует `/api`, включая WebSocket, на `http://localhost:8080`.

Для рабочих регистрации, входа и семейных данных нужен запущенный Go API с базой и настроенной почтой. Данные этих разделов не заменяются локальными демонстрационными записями при недоступности API. Инструкции: [backend](../backend/README.md) и [общий запуск](../README.md#запуск-через-docker).

При запуске Go API напрямую остановите Docker-сервисы `frontend` и `backend`, занимающие порт 8080; базу можно оставить в Docker. Её адрес с компьютера — `127.0.0.1:15432`.

## Устройство

| Каталог | Назначение |
| --- | --- |
| `src/api` | HTTP-клиент, обновление сессии, преобразование данных, WebSocket чатов |
| `src/store` | Профиль и семейные данные, действия страниц, тема, локальные демонстрационные разделы |
| `src/pages` | Страницы; маршруты подключаются в `src/App.jsx` |
| `src/components` | Общие элементы, формы и диалоги |
| `src/layouts` | Оболочки авторизации, приложения и отдельных страниц |
| `src/i18n` | Русский, английский, испанский, немецкий, китайский и японский языки |
| `src/legal` | Тексты документов, версия и заглушки реквизитов оператора |
| `src/styles` | Общие стили и токены светлой и тёмной тем |
| `src/utils` | Даты, права, бюджет, тарифы и вспомогательные функции |

Access-токен хранится в памяти, refresh-токен — в HttpOnly cookie. Регистрация и вход проходят через код на почту; запрос подтверждения хранится в `sessionStorage`. Сброс пароля доступен по `/Famigo/password-reset`. Сервер проверяет наличие аккаунта до перехода к коду, после смены пароля пользователь входит заново.

Вкладки одного профиля браузера разделяют refresh-cookie. Для одновременного входа
под разными пользователями нужны разные профили/браузеры или отдельное инкогнито.

## Формы входа и регистрации

- Регистрация проверяет минимум 8 символов, латинскую букву, цифру и специальный
  символ; максимум — 72 байта. Подсказка меняется во время ввода, перечисляет
  только недостающие требования и исчезает, когда пароль подходит.
- У каждого поля пароля есть отдельная кнопка просмотра/скрытия. Примеры букв
  и знаков указаны в динамической подсказке; пробел не считается знаком.
- При настроенной SmartCaptcha регистрация требует проверку сразу. На входе
  капча появляется после первой неверной почты/пароля. Пока токен не получен,
  кнопка продолжения заблокирована; Enter также не обходит проверку формы.
- `useCaptcha` получает публичные настройки из `/api/auth/captcha`. Компонент
  `SmartCaptcha` загружает SDK Яндекса, очищает просроченный токен и сбрасывает
  виджет после неудачной отправки. Ошибка загрузки показывает повторную попытку.
- Ключ сервера не входит в сборку и не выдаётся браузеру. Требование капчи,
  сложность пароля и действительность токена повторно проверяются backend.
- Виджет подстраивается под узкий контейнер и светлую/тёмную тему. Все подписи
  Famigo переведены на шесть языков; у виджета используются RU/EN.

Ключи задаются только на стороне backend: [настройка SmartCaptcha](../backend/README.md#yandex-smartcaptcha).

## Рецепты и избранное

`AiSuggest` запрашивает пять рецептов для выбранного дома, категории, порций и
участников. Во время генерации выбор заблокирован. Результат можно добавить
в личное избранное или отправить в доступный чат через `ChatShare`.
`Favorites` загружает сохранённые рецепты из `/api/me/recipes`; это серверные
записи, а не встроенный каталог и не данные локальной галереи.

Язык запроса передаётся модели при генерации. После смены языка название,
ингредиенты и шаги уже сохранённого рецепта остаются исходными. Кнопки, порции,
время и известные единицы измерения локализуются при отображении.
`src/utils/recipeAmount.js` заменяет распознанные единицы, не меняя количества
и сохранённый JSON рецепта.

Видимость категории «Алкоголь» определяется серверным `canUseAlcohol` из `/api/me`.
Она скрыта без подтверждённого сервером совершеннолетия по дате рождения;
backend дополнительно проверяет автора запроса и выбранных едоков.

## Чаты

`Chat` и `src/components/ChatShare` поддерживают текст, рецепты, ответы, пересылку
и фото/видео. В меню скрепки выбирается файл или съёмка камерой на поддерживаемом
устройстве. Один файл — до 25 МиБ; HEIC конвертируется в JPEG до отправки.
Файлы загружаются как защищённые Blob через API; объектные URL освобождаются
при размонтировании. Фото открывается в просмотрщике с именем файла и закрывается
по клику вне картинки, Escape или крестику; видео воспроизводится в сообщении.

Действия ответа и пересылки находятся только в контекстном меню: ПКМ, долгое
нажатие на телефоне либо Shift+F10. В присланном рецепте нет кнопок сохранения
и отправки; приготовление раскрывается внутри карточки. Клик по цитате
прокручивает к оригиналу и подсвечивает его; отсутствующий оригинал вызывает
подгрузку страниц истории. Изначально загружается до 100 сообщений.

Аватарка каждого входящего сообщения открывает профиль его отправителя.
Возврат восстанавливает сохранённую позицию соответствующей записи истории чата.
У собственных сообщений аватарка отсутствует. Изменение аватарки семьи пока
заглушка, и ссылка показана только владельцу и администратору.

`useMessageViews` использует IntersectionObserver: сообщает backend ID сообщений,
которые попали в видимую область активной вкладки. Скрытая вкладка и открытый
просмотрщик не отправляют новые просмотры. Открытие чата и собственный ответ
сами по себе не читают всю историю. Статус вычисляет сервер, а не таймер:
одна галочка — «Доставлено», две — «Прочитано» всеми остальными участниками.
Ключи переводов статусов хранятся отдельно от текста, поэтому смена языка
не требует повторной отправки или генерации сообщения.

Медиа чата хранится на сервере. Локальная демонстрационная галерея — отдельная
функция; её тарифные лимиты не являются суммарной серверной квотой вложений чата.

Карта, геолокация, галерея и check-in используют локальное демонстрационное состояние; у SOS сообщение отправляется через семейный чат. Оплата демонстрационная. QR-сканер заполняет сумму и дату расхода, но не загружает позиции чека. Полная таблица статусов и тарифов — в [корневом README](../README.md#возможности).

На сайте три основных документа: соглашение, политика и согласие на обработку данных. Условия питания и геолокации включены в основное согласие; прежние идентификаторы `food` и `geo` открывают его. Юридические тексты пока имеют статус проекта с незаполненными реквизитами.

## Семейные подписки

`Premium` показывает цены за всю семью: Premium — 499 ₽/мес. или 4 990 ₽/год,
Premium+ — 1 499 ₽/мес. или 14 990 ₽/год. Все участники видят текущий тариф и
пользуются его возможностями. Покупка, смена тарифа и управление продлением
показаны только Owner/Admin; признак `payerId` не даёт дополнительных прав.
Проверка `canManageSubscription` применяется и к странице тарифов, и к диалогу
оформления. Подписи о семейной цене и полномочиях переведены на все шесть языков.
Оплата остаётся демонстрационной. Цены синхронизированы с backend в
`src/utils/plans.js` и `backend/internal/subscriptions/plans.go`.

Плановые расходы и доходы обоих тарифов: [экономика проекта](../_docs/economics.md).

## Проверки и сборка

```bash
npm run lint
npm run build
npm run preview
```

Результат сборки — `dist/`. Предпросмотр проверяет статическую сборку; production-сервер и API он не разворачивает. Для запросов API по-прежнему нужен отдельно запущенный Go-сервер; для общего запуска используйте Docker с nginx.

Отдельного набора frontend unit- и end-to-end-тестов пока нет. Сборка предупреждает о крупных JavaScript-бандлах.

## Публикация

В Docker nginx раздаёт SPA по `/Famigo/` и проксирует `/api` к backend. Общий запуск описан в корневом README.

`npm run deploy` собирает приложение, копирует `index.html` в `404.html` и запускает `deploy.mjs`. Скрипт принудительно обновляет ветку `gh-pages` удалённого `origin`; выполняйте его только для намеренной публикации. Это публикация статического интерфейса: backend, PostgreSQL и почта отдельно не разворачиваются. Без доступного `/api` авторизация и семейные данные работать не будут.
