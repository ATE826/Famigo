# Famigo — frontend

Интерфейс Famigo на JavaScript/JSX, React 19, React Router 7 и Vite 8 с React Compiler. Стили — CSS Modules и общие CSS-переменные. Данные и действия страниц предоставляет React Context. TypeScript в исходниках не используется.

Документация обновлена **26.11.2026**; сценарии чатов сверены с текущим кодом.

## Запуск для разработки

Для Node.js 22 используйте версию 22.12 или новее; полный диапазон совместимости указан в зависимостях Vite. Из корня репозитория:

```bash
cd frontend
npm ci
npm run dev
```

Адрес: [http://localhost:5173/](http://localhost:5173/). Базовый путь `/` задан в `vite.config.js`; `BrowserRouter` использует `import.meta.env.BASE_URL`. Vite проксирует `/api`, включая WebSocket, на `http://localhost:8080`.

Для рабочих регистрации, входа и семейных данных нужен запущенный Go API с базой и настроенной почтой. Данные этих разделов не заменяются локальными демонстрационными записями при недоступности API. Инструкции: [backend](../backend/README.md) и [общий запуск](../README.md#запуск-через-docker).

При запуске Go API напрямую остановите Docker-сервисы `frontend` и `backend`, занимающие порт 8080; базу можно оставить в Docker. Её адрес с компьютера — `127.0.0.1:15432`.

## Устройство

| Каталог | Назначение |
| --- | --- |
| `src/api` | HTTP-клиент, обновление сессии, преобразование данных, WebSocket чатов |
| `src/store` | Профиль и семейные данные, действия страниц, тема, локальные демонстрационные разделы |
| `src/pages` | Страницы; маршруты подключаются в `src/App.jsx` |
| `src/components` | Общие элементы, формы и диалоги |
| `src/layouts` | Оболочки авторизации, приложения и отдельных страниц |
| `src/i18n` | Русский, английский, испанский, немецкий, китайский и японский языки |
| `src/legal` | Тексты документов, версия и заглушки реквизитов оператора |
| `src/styles` | Общие стили и токены светлой и тёмной тем |
| `src/utils` | Даты, права, бюджет, тарифы и вспомогательные функции |

Access-токен хранится в памяти, refresh-токен — в HttpOnly cookie. Регистрация и вход проходят через код на почту; запрос подтверждения хранится в `sessionStorage`. Сброс пароля доступен по `/password-reset`. Сервер проверяет наличие аккаунта до перехода к коду, после смены пароля пользователь входит заново.

Вкладки одного профиля браузера разделяют refresh-cookie. Для одновременного входа
под разными пользователями нужны разные профили/браузеры или отдельное инкогнито.

## Формы входа и регистрации

- Регистрация проверяет минимум 8 символов, латинскую букву, цифру и специальный
  символ; максимум — 72 байта. Подсказка меняется во время ввода, перечисляет
  только недостающие требования и исчезает, когда пароль подходит.
- У каждого поля пароля есть отдельная кнопка просмотра/скрытия. Примеры букв
  и знаков указаны в динамической подсказке; пробел не считается знаком.
- При настроенной SmartCaptcha регистрация требует проверку сразу. На входе
  капча появляется после первой неверной почты/пароля. Пока токен не получен,
  кнопка продолжения заблокирована; Enter также не обходит проверку формы.
- `useCaptcha` получает публичные настройки из `/api/auth/captcha`. Компонент
  `SmartCaptcha` загружает SDK Яндекса, очищает просроченный токен и сбрасывает
  виджет после неудачной отправки. Ошибка загрузки показывает повторную попытку.
- Ключ сервера не входит в сборку и не выдаётся браузеру. Требование капчи,
  сложность пароля и действительность токена повторно проверяются backend.
- Виджет подстраивается под узкий контейнер и светлую/тёмную тему. Все подписи
  Famigo переведены на шесть языков; у виджета используются RU/EN.

Ключи задаются только на стороне backend: [настройка SmartCaptcha](../backend/README.md#yandex-smartcaptcha).

## Рецепты и избранное

`AiSuggest` запрашивает пять рецептов для выбранного дома, категории, порций и
участников. Во время генерации выбор заблокирован. Результат можно добавить
в личное избранное или отправить в доступный чат через `ChatShare`.
`Favorites` загружает сохранённые рецепты из `/api/me/recipes`; это серверные
записи, а не встроенный каталог и не данные локальной галереи.

Язык запроса передаётся модели при генерации. После смены языка название,
ингредиенты и шаги уже сохранённого рецепта остаются исходными. Кнопки, порции,
время и известные единицы измерения локализуются при отображении.
`src/utils/recipeAmount.js` заменяет распознанные единицы, не меняя количества
и сохранённый JSON рецепта.

Видимость категории «Алкоголь» определяется серверным `canUseAlcohol` из `/api/me`.
Она скрыта без подтверждённого сервером совершеннолетия по дате рождения;
backend дополнительно проверяет автора запроса и выбранных едоков.

## Чаты

`src/pages/Chat` и `src/components/ChatShare` поддерживают текст, рецепты,
ответы, пересылку, фото/видео, альбомы, голосовые и видеокружочки. Новые подписи
и статусы переведены на русский, английский, немецкий, испанский, китайский
и японский. Содержимое сообщений, подписей и рецептов автоматически не переводится.

### Вложения и черновик

Скрепка открывает выбор из файлов/галереи или съёмку камерой на поддерживаемом
устройстве. Фото и видео также можно перетащить в область чата. Файлы сначала
попадают в предпросмотр над полем ввода; до нажатия отправки загрузки на сервер нет.
Можно добавить ещё файлы, убрать один или очистить весь список. Поле ввода
используется для общей подписи; отправка без подписи тоже разрешена.

Лимиты: 10 файлов, до 25 МиБ каждый, до 100 МиБ суммарно; подпись — до 2000 символов.
HEIC преобразуется в JPEG до отправки. Один запрос создаёт одно сообщение:
несколько фото/видео показываются адаптивной сеткой-коллажем с общей подписью
и статусом. Весь альбом выбирается, пересылается и удаляется как одно сообщение.
Ошибка отправки оставляет файлы и текст для повторной попытки. При уходе из чата
черновик вложений очищается; временные Blob URL освобождаются.

### Голосовые и видеокружочки

Короткое нажатие на кнопку справа от пустого поля переключает режимы.
Удержание начинает запись, отпускание отправляет; движение вверх на 70 px
фиксирует запись до отдельного нажатия отправки или Enter. Кружочек ограничен
60 секундами, затем автоматически отправляется. Ввод текста заменяет кнопку
записи кнопкой отправки; выбранные вложения также включают обычную отправку.

Предпросмотр кружочка находится по центру чата и всегда обрезается круглой маской.
Поток подключается один раз и не переназначается при обновлении таймера.
Таймер показывает, например, `0:12 / 1:00`. Во время просмотра кружочка видна
текущая позиция, на паузе и после окончания — длительность. После окончания
повторное воспроизведение начинается сначала. В чате нет прямоугольной подложки
вокруг самого кружочка.

У голосового есть плеер с перемоткой и звуковой дорожкой. Живая амплитуда
читается через Web Audio AnalyserNode; для полученного файла — decodeAudioData.
Если декодирование для анализа недоступно, остаются плеер и нейтральная дорожка,
без подстановки случайных амплитуд. Подсказка `title` у кнопки записи удалена,
чтобы браузерный tooltip не мелькал во время удержания.

Используются getUserMedia и MediaRecorder с поддерживаемым WebM/MP4/OGG.
Нужны HTTPS либо localhost и разрешение микрофона, для кружочка также камеры.
При уходе со страницы или скрытии вкладки незавершённая запись отменяется,
медиадорожки останавливаются. После ошибки готовую запись можно отправить повторно.
Лимит файла записи — 25 МиБ. Поддержка кодеков и съёмки зависит от браузера.

### Контекстное меню, выбор и удаление

Меню открывается ПКМ, долгим нажатием на телефоне или Shift+F10. В обычном виде
ответ и пересылка не висят под сообщениями. В присланном рецепте нет кнопок
сохранения и отправки; приготовление раскрывается внутри карточки.

| Действие | Собственное сообщение | Чужое сообщение |
| --- | --- | --- |
| Ответить | Да, только на одно сообщение | Да, только на одно сообщение |
| Переслать | Да | Да |
| Выбрать | Да | Да |
| Удалить у себя / у всех | Да | Нет, независимо от роли в семье |

«Выбрать» включает режим выбора нескольких сообщений нажатием. Панель показывает
количество и пересылку; удаление доступно, только если все выбранные сообщения
собственные. Кнопки действий без выбора отключены или скрыты. Ответить на
несколько сообщений нельзя. Пересылка отправляет сообщения в один выбранный чат
по порядку; после частичного сбоя повтор продолжает с первого неподтверждённого
сообщения. Если ответ сервера потерян, это не даёт гарантии отсутствия дубля.

Удаление открывает диалог «Удалить у себя» / «Удалить у всех» и выполняется
после подтверждения сервером. Личное скрытие применяется к своему аккаунту на
его устройствах; общее удаление распространяется участникам через WebSocket.
Строка исчезает с анимацией без надписи «Сообщение удалено»; уменьшение анимации
учитывается. Сервер проверяет авторство для обоих вариантов.

### Просмотр медиа

Фото открывается нажатием, у обычного видео есть кнопка раскрытия. Просмотрщик
листит фото и видео из загруженных сообщений этого чата, включая все элементы
альбомов; голосовые, кружочки и удалённые сообщения исключены. Стрелки по краям
и клавиши ← / → переключают файлы без закрытия просмотра. На границах стрелка
отключается; шапка показывает имя и номер файла.

Закрытие — крестик, Escape или клик по фону; фокус возвращается к исходной кнопке,
если она ещё существует. Предыдущее видео явно ставится на паузу при переключении
или закрытии. Быстрая навигация отменяет предыдущую загрузку через AbortController,
Blob URL освобождаются; старое изображение не показывается вместо загружаемого.
Начальное фото использует уже загруженный URL из сообщения. Имена файлов рядом
с изображениями в чате не показываются.

### Прочтение, набор текста и навигация

`useMessageViews` использует IntersectionObserver: backend получает только ID
сообщений, которые видны в активной вкладке. Скрытая вкладка и открытый просмотрщик
не отправляют новые просмотры. Открытие чата и собственный ответ не читают историю.
Одна галочка — «Доставлено», две — «Прочитано» всеми остальными текущими участниками.
Ключи переводов статусов отделены от содержимого сообщений.

Над полем ввода видны имена печатающих участников без своего имени: до трёх
имён списком, при большем числе — два имени и количество остальных. Клиент
посылает статус не чаще раза в две секунды; пауза в три секунды, очистка поля,
отправка, уход из чата, скрытие или потеря фокуса окна снимают статус. Сервер
также очищает его по таймеру. Событие не содержит текста и не сохраняется в БД.

Цитата прокручивает к оригиналу и ненадолго подсвечивает его. Изначально загружены
100 последних сообщений; для отсутствующего оригинала догружаются страницы.
Если история недоступна, показывается ошибка. Новые сообщения не сбивают чтение
выше по истории. Галерея просмотра также ограничена загруженной историей.

Аватарка каждого входящего сообщения открывает профиль отправителя, возврат
восстанавливает позицию соответствующей записи истории чата. У собственных
сообщений аватарки нет. На телефоне высота чата следует за VisualViewport:
поле ввода остаётся над клавиатурой, прокручивается переписка внутри чата.

### Клавиатура

| Клавиша | Контекст | Действие |
| --- | --- | --- |
| Enter / Space | Фокус на кнопке записи, запись ещё не начата | Начать закреплённую запись |
| Enter | Идёт запись | Завершить и отправить |
| Enter | Готовая запись после ошибки отправки | Повторить отправку |
| Delete | Выбраны только свои сообщения | Открыть диалог удаления |
| Delete | Фокус в поле ввода | Продолжить редактирование текста |
| ← / → | Открыт просмотрщик | Предыдущее / следующее медиа |
| Escape | Открыт просмотрщик или режим выбора | Закрыть просмотр / завершить выбор |
| Shift+F10 | Фокус на сообщении | Открыть контекстное меню |

Удержание Enter не запускает повторную отправку; сочетания с модификаторами и
IME-ввод не обрабатываются как обычный Enter. Открытые диалоги сохраняют своё
управление. Delete не действует для смешанного выбора с чужими сообщениями.
Выбор также завершается крестиком или кнопкой назад в шапке.

### Файлы реализации и оформление

| Файл / компонент | Назначение |
| --- | --- |
| `Chat.jsx`, `Chat.module.css` | Список сообщений, выбор, панель действий, галерея текущего чата и горячая клавиша Delete |
| `useChatViewport.js` | Высота чата и положение поля ввода при мобильной клавиатуре |
| `AttachmentDraft.jsx`, `useAttachmentDraft.js` | Подготовка, предпросмотр и очистка неотправленных вложений |
| `Recorder.jsx`, `Recorder.module.css` | Запись, закрепление, таймер и отправка по Enter |
| `MessagePresence.jsx`, `DeleteMessageDialog.jsx` | Анимация исчезновения и подтверждение удаления |
| `MessageContent.jsx`, `MediaViewer.jsx` | Рецепт, цитата, медиа/коллаж и просмотр со стрелками |

| `MessageMenu.jsx`, `ChatShare.jsx` | Контекстное меню и последовательная пересылка выбранных сообщений |

Медиа имеет компактную рамку с равномерным отступом 6 px, коллаж обрезается
по общему скруглению. Стрелка отправки оптически сдвинута на 1 px влево и
на 1 px вниз (`translate(-1px, 1px)`) относительно геометрического центра:
правило применяется и к обычной отправке, и к отправке записи, не к стрелкам
просмотрщика. Адаптивные размеры и цвета используют общие токены проекта.

Медиа чата сохраняется на сервере. Локальная демонстрационная галерея — отдельный
раздел; её тарифные лимиты не являются суммарной квотой файлов чата. Загрузка
аватарки семьи пока заглушка, доступная в интерфейсе только Owner/Admin.

### Остальные разделы

Карта, геолокация, галерея и check-in используют локальное демонстрационное состояние; у SOS сообщение отправляется через семейный чат. Оплата демонстрационная. QR-сканер заполняет сумму и дату расхода, но не загружает позиции чека. Полная таблица статусов и тарифов — в [корневом README](../README.md#возможности).

На сайте три основных документа: соглашение, политика и согласие на обработку данных. Условия питания и геолокации включены в основное согласие; прежние идентификаторы `food` и `geo` открывают его. Юридические тексты пока имеют статус проекта с незаполненными реквизитами.

## Семейные подписки

`Premium` показывает цены за всю семью: Premium — 499 ₽/мес. или 4 990 ₽/год,
Premium+ — 1 499 ₽/мес. или 14 990 ₽/год. Все участники видят текущий тариф и
пользуются его возможностями. Покупка, смена тарифа и управление продлением
показаны только Owner/Admin; признак `payerId` не даёт дополнительных прав.
Проверка `canManageSubscription` применяется и к странице тарифов, и к диалогу
оформления. Подписи о семейной цене и полномочиях переведены на все шесть языков.
Оплата остаётся демонстрационной. Цены синхронизированы с backend в
`src/utils/plans.js` и `backend/internal/subscriptions/plans.go`.

Плановые расходы и доходы обоих тарифов: [экономика проекта](../_docs/economics.md).

### Дома сверх тарифа

Список сохраняет карточки всех домов. Для домов сверх текущего семейного тарифа показывается плашка о недоступности; детали, редактирование, дела и холодильник заменяются экраном ограничения. Free открывает первые 2 дома, Premium — первые 3, Premium+ — все. Закрытые дома не загружают дела и продукты. После оформления тарифа данные перечитываются; остальные участники получают обновление при возвращении в окно или в течение 30 секунд. Сервер проверяет доступ независимо от интерфейса.

## Проверки и сборка

```bash
npm run lint
npm run build
npm run preview
```

Результат сборки — `dist/`. Предпросмотр проверяет статическую сборку; production-сервер и API он не разворачивает. Для запросов API по-прежнему нужен отдельно запущенный Go-сервер; для общего запуска используйте Docker с nginx.

Для обновлений чатов выполнены разовые проверки в отдельном браузере Playwright
на тестовых данных: предпросмотр/коллаж/подпись, ошибка отправки с сохранением
черновика, drag-and-drop, Enter/Delete, защита чужих сообщений, просмотр со
стрелками, остановка видео и закрытие. Проверялись размеры 320/390 px и темы.

в репозитории пока нет. ESLint изменённых компонентов и сборка проходили;

## Публикация

После правок при работе через Docker нужен новый образ. Из корня проекта:

```bash
docker compose --env-file .env --env-file secrets.env up -d --build
```

Если изменён только frontend, можно добавить `--no-deps frontend`. При изменении
контракта медиа, миграций или backend собирайте также backend. Локальный запуск
не обновляет `/opt/famigo` на сервере; серверные секреты и тома сохраняйте отдельно.
После обновления интерфейса при необходимости используйте Ctrl+F5.

В Docker nginx раздаёт SPA в корне `/` и перенаправляет старые ссылки `/Famigo/…` без префикса и проксирует `/api` к backend. Общий запуск описан в корневом README.

`npm run deploy` отдельно собирает интерфейс с базой `/Famigo/` для GitHub Pages, копирует `index.html` в `404.html` и запускает `deploy.mjs`. Скрипт принудительно обновляет ветку `gh-pages` удалённого `origin`; выполняйте его только для намеренной публикации. Это публикация статического интерфейса: backend, PostgreSQL и почта отдельно не разворачиваются. Без доступного `/api` авторизация и семейные данные работать не будут.
