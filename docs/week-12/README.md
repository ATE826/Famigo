# Шаг 1. Определение «ядра роста» и целей

## Выбран: B2C-канал продаж

Для Famigo основным каналом роста является **B2C**, поскольку продукт предназначен непосредственно для семей и небольших домохозяйств.

Основная модель монетизации — **Freemium**: базовые функции доступны бесплатно, а расширенные возможности предоставляются по Premium-подписке стоимостью **249 ₽/мес**.

| Критерий                       | Почему B2C-канал                                                                                                                               |
| ------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| **Соответствие продукту**      | Famigo непосредственно предназначен для семей и создаётся как единое цифровое пространство для нескольких членов семьи.                        |
| **Низкий барьер входа**        | Бесплатная версия позволяет пользователю попробовать основные функции без оплаты.                                                              |
| **Виральность**                | Один пользователь может пригласить членов своей семьи, что позволяет получать новых пользователей без отдельного привлечения каждого человека. |
| **Масштабируемость**           | После создания продукта можно привлекать большое количество семей без необходимости заключать отдельные договоры с организациями.              |
| **Проверяемость**              | Гипотезу можно проверить на небольшой выборке из 20–30 семей и постепенно увеличивать аудиторию.                                               |
| **Регулярность использования** | Бюджет, календарь, продукты, дом и семейный чат могут использоваться семьёй регулярно.                                                         |
| **Простая модель оплаты**      | Один член семьи оплачивает Premium, после чего расширенные возможности доступны всей семейной группе.                                          |

# Шаг 3. Основные показатели роста

## Ключевые метрики

| Метрика                    | Формула                                          | Что показывает                                    |
| -------------------------- | ------------------------------------------------ | ------------------------------------------------- |
| **Activation Rate**        | Активные семьи / зарегистрированные семьи × 100% | Насколько пользователи понимают ценность продукта |
| **Family Invitation Rate** | Семьи с приглашением / созданные семьи × 100%    | Готовность использовать Famigo совместно          |
| **Premium Conversion**     | Платящие семьи / активные семьи × 100%           | Готовность пользователей платить                  |
| **MRR**                    | Платящие семьи × 249 ₽                           | Ежемесячную повторяющуюся выручку                 |
| **Churn Rate**             | Отказавшиеся от подписки / платящие семьи × 100% | Уровень оттока                                    |
| **Retention Rate**         | Вернувшиеся семьи / активные семьи × 100%        | Регулярность использования                        |
| **ARPU**                   | Выручка / количество платящих семей              | Средний доход с платящей семьи                    |
| **LTV**                    | ARPU × средний срок подписки                     | Потенциальную ценность клиента                    |

# Шаг 5. План роста продукта

## Этап 1 — 0–3 месяца

Основная задача — проверить ценность продукта.

### Действия:

- запустить MVP;
- привлечь первые 50–100 семей;
- проверить создание семейных групп;
- проверить приглашение участников;
- определить наиболее востребованные функции;
- измерить повторное использование;
- протестировать Premium за 249 ₽/мес.

### Целевой результат:

- 50+ семей протестировали продукт;
- 25+ семей используют Famigo регулярно;
- 5+ семей готовы платить;
- выявлены основные проблемы MVP.

# Итог

Основная стратегия роста Famigo — **B2C-модель с Freemium-монетизацией**.

Пользователь может бесплатно создать семейную группу, пригласить членов семьи и использовать основные функции:

- семейный бюджет;
- календарь;
- продукты;
- дом и инвентарь;
- семейный чат.

Расширенные возможности предоставляются в Premium за **249 ₽/мес**.

Основным механизмом роста является приглашение членов семьи. Один пользователь создаёт семейную группу и приглашает других участников, благодаря чему Famigo может получать несколько активных пользователей из одной точки привлечения.

В течение первых трёх месяцев основная задача — подтвердить ценность продукта и проверить, используют ли семьи его совместно и регулярно.

В течение 4–9 месяцев основной фокус переносится на удержание пользователей, улучшение продукта и увеличение количества платящих семей.

К 12 месяцу базовый сценарий предполагает:

- **320 платящих семей;**
- **249 ₽/мес** стоимость Premium;
- **79 680 ₽ MRR;**
- около **956 160 ₽ ARR;**
- около **35 000 ₽ ежемесячных затрат;**
- около **44 680 ₽ операционной прибыли в месяц;**
- выход в операционный плюс примерно на **10 месяце**.

Таким образом, базовый сценарий Famigo является реалистичным при условии постепенного роста аудитории, сохранения умеренных расходов и достижения конверсии активных семей в Premium на уровне около 8%.

Главная задача проекта на первом году — доказать не максимальный объём аудитории, а наличие устойчивой связки:

**активная семья → регулярное использование → несколько участников → Premium за 249 ₽/мес → повторяющаяся выручка.**
