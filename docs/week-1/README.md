#### 1. Идея: Famigo — единое цифровое пространство для семьи

### Проблема

Семейная жизнь связана с большим количеством повседневных задач: планированием дел, ведением бюджета, покупками, организацией домашних дел, общением и контролем местоположения членов семьи. Для решения этих задач люди используют разные приложения: мессенджеры, банковские приложения, календари, карты, списки покупок и заметки.

В результате информация оказывается разбросана по разным сервисам. Пользователю приходится постоянно переключаться между приложениями, а члены семьи не имеют единого пространства для совместного управления повседневными задачами.

### Решение

Famigo — веб-приложение, которое объединяет основные инструменты для организации семейной жизни в одном цифровом пространстве.

Сервис позволяет:

- создавать и управлять семейной группой;
- вести общий семейный бюджет;
- создавать события в общем календаре;
- управлять домами и их содержимым;
- вести список продуктов;
- просматривать местоположение членов семьи;
- общаться в семейных чатах;
- получать уведомления.

В Famigo предусмотрено **два вида пользователей: обычный и премиум**.

**Обычный пользователь** получает доступ к основным возможностям сервиса, но имеет следующие ограничения:

- отсутствие возможности просматривать местоположение членов семьи;
- отсутствие возможности создавать события в общем календаре;
- ограничение количества членов семьи до **4 пользователей**;
- отсутствие доступа к нейросетевой функции подбора рецептов на основе продуктов, имеющихся в доме.

**Премиум-пользователь** получает доступ к расширенным возможностям сервиса, включая просмотр местоположения членов семьи, создание событий в общем календаре, увеличение допустимого количества участников семьи и дополнительные функции, которые будут добавляться в последующих обновлениях.

Главная особенность Famigo — взаимосвязь функций.

Например:

> Покупка продуктов → список продуктов → расход → семейный бюджет.

Или:

> Событие → участники → место → напоминание → уведомление → чат.

### Актуальность / Ликвидность

Организация семейной жизни является постоянной потребностью для семей и пар, которым необходимо совместно планировать расходы, покупки, события и домашние дела.

Потенциальная аудитория Famigo — семьи и пары, которые хотят совместно управлять повседневными задачами и информацией. Особенно актуальным сервис может быть для семей с детьми, где увеличивается количество общих расходов, событий, покупок и домашних задач.

Монетизация продукта может осуществляться по модели **Freemium**: основные возможности доступны обычным пользователям бесплатно, а расширенный функционал предоставляется премиум-пользователям по подписке.

### Конкуренты

К прямым конкурентам Famigo относятся **FamilyWall, FamSpace, FamilyNow, Monetoni, Best4Family, Cozi, FamilyDash, FamCal, Domownik, Family Planner, МультиОрганайзер, Toggly, Семейный планер и MomPlan**.

Косвенными конкурентами являются сервисы, закрывающие отдельные потребности семьи: **Наш список, Яндекс, VK, Сбер, Т-Банк, 2ГИС, Купер, Яндекс Лавка и Telegram**.

Большинство конкурентов специализируется на отдельных направлениях — календаре, финансах, покупках, геолокации или общении. Famigo отличается объединением этих функций в едином семейном пространстве.

### Вывод

Несмотря на наличие большого количества сервисов для отдельных семейных задач, информация по-прежнему распределена между разными приложениями.

Famigo объединяет бюджет, календарь, покупки, дома, геолокацию и общение в одном сервисе. Freemium-модель позволяет предоставить пользователям основные возможности бесплатно, одновременно создавая дополнительную ценность для премиум-пользователей за счёт расширенного функционала.

В последующих улучшениях для премиум-пользователей планируется внедрение **нейросетевой функции, которая на основе имеющихся в доме продуктов сможет предлагать подходящие рецепты**.

Таким образом, Famigo может стать единым цифровым пространством для управления семейной жизнью, объединяющим повседневные задачи, коммуникацию и интеллектуальные рекомендации.
