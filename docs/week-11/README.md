# Практическое занятие: Финальная проверка MVP

## Шаг 1. Контроль соответствия MVP исходным гипотезам

## **Сегмент**

Семьи — люди, которые хотят совместно организовывать семейную жизнь, управлять общими расходами, планировать события, контролировать продукты и содержимое дома, а также общаться в одном цифровом пространстве.

## **Проблема**

Информация о семейной жизни распределена между разными сервисами: расходы могут храниться в банковских приложениях или таблицах, семейные события — в календаре, список продуктов — в заметках, бытовая информация — отдельно, а общение — в мессенджерах. Из-за этого участникам семьи сложно поддерживать общую и актуальную информацию.

## **Ценность**

Возможность объединить основные процессы семейной жизни в одном общем цифровом пространстве, где члены семьи могут совместно управлять бюджетом, календарём, продуктами, информацией о доме и общаться друг с другом.

## **Целевое действие на MVP**

Создание семейной группы и приглашение в неё хотя бы одного члена семьи.

## **Что считаем «успехом»**

70% зарегистрированных пользователей создают семейную группу, а 50% созданных семейных групп приглашают хотя бы одного участника.

### Ответы на контрольные вопросы

**Каким образом MVP решает заявленную проблему?**

MVP объединяет основные инструменты для организации семейной жизни в одном пространстве. Пользователь может создать семейную группу, пригласить членов семьи, вести общий бюджет, планировать события, отслеживать продукты и содержимое дома, хранить информацию о доме и общаться в общем чате.

Таким образом, семье не приходится использовать несколько отдельных сервисов для решения повседневных задач. Все основные данные доступны участникам семейной группы в одном приложении.

**Соответствует ли продукт первоначальной концепции и гипотезам ЦА?**

Да, MVP соответствует первоначальной концепции семейного цифрового пространства. Основные функции ориентированы на совместное использование информации несколькими членами семьи.

Главная гипотеза заключается в том, что пользователи готовы объединять членов семьи в одном цифровом пространстве и использовать его для решения повседневных семейных задач.

### Анализ

**Какие фичи можно убрать без потери основной ценности?**

- Аватарки и расширенное оформление профилей — не влияют на основные семейные сценарии.
- Категории расходов — базовый учёт доходов и расходов возможен без расширенной системы категорий.
- Связь покупок с содержимым дома — является дополнительным удобством.
- История расходов — базовый бюджет может работать без расширенной истории и анализа.
- Расширенные возможности уведомлений — для MVP достаточно базовых уведомлений.

**Какие фичи нужно добавить, если без них ключевой сценарий «ломается»?**

- Обработка ошибок регистрации и авторизации.
- Обработка ошибок создания и присоединения к семейной группе.
- Понятное отображение прав доступа пользователей.
- Индикаторы загрузки при сохранении и обновлении данных.
- Подтверждение успешного добавления, изменения или удаления данных.

# Шаг 4. Гипотетическая проверка метрик и воронки

**NSM:** Количество активных семейных групп с двумя и более участниками, использующих хотя бы одну общую функцию.

### Ответы на вопросы

**Какие ключевые метрики стоило бы отслеживать?**

В первую очередь необходимо отслеживать количество зарегистрированных пользователей, долю пользователей, создавших семейную группу, долю пользователей, пригласивших членов семьи, количество присоединившихся участников и количество активных семейных групп.

Дополнительно необходимо отслеживать использование основных функций: количество финансовых операций, событий календаря, добавленных продуктов и сообщений в семейном чате.

**Как можно было бы проверить вовлечённость пользователей?**

Вовлечённость можно оценивать по повторным посещениям семейного пространства, количеству действий внутри группы и частоте использования основных функций.

Также важным показателем является количество активных семейных групп, в которых регулярно несколько участников добавляют или изменяют общие данные.

**Как бы выглядела воронка взаимодействия?**

Регистрация → вход → создание семейной группы → приглашение членов семьи → присоединение участников → добавление общих данных → использование основных функций → повторное использование семейного пространства.

# Итог

Основная модель монетизации Famigo — **Freemium с Premium-подпиской для семей**.

Бесплатная версия позволяет пользователю создать семейную группу и использовать основные функции: бюджет, календарь, продукты, дом и чат. Это снижает барьер входа и позволяет проверить основную гипотезу продукта.

Платная версия стоимостью около **249 ₽/мес** предоставляет расширенные возможности, которые повышают удобство и глубину использования сервиса.

На следующем этапе необходимо проверить две ключевые гипотезы:
