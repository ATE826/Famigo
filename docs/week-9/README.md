# Практическое занятие: Финальная проверка MVP

## Шаг 1. Контроль соответствия MVP исходным гипотезам

## **Сегмент**

Семьи — люди, которые хотят совместно организовывать семейную жизнь, управлять общими расходами, планировать события, контролировать продукты и содержимое дома, а также общаться в одном цифровом пространстве.

## **Проблема**

Информация о семейной жизни распределена между разными сервисами: расходы могут храниться в банковских приложениях или таблицах, семейные события — в календаре, список продуктов — в заметках, бытовая информация — отдельно, а общение — в мессенджерах. Из-за этого участникам семьи сложно поддерживать общую и актуальную информацию.

## **Ценность**

Возможность объединить основные процессы семейной жизни в одном общем цифровом пространстве, где члены семьи могут совместно управлять бюджетом, календарём, продуктами, информацией о доме и общаться друг с другом.

## **Целевое действие на MVP**

Создание семейной группы и приглашение в неё хотя бы одного члена семьи.

## **Что считаем «успехом»**

70% зарегистрированных пользователей создают семейную группу, а 50% созданных семейных групп приглашают хотя бы одного участника.

### Ответы на контрольные вопросы

**Каким образом MVP решает заявленную проблему?**

MVP объединяет основные инструменты для организации семейной жизни в одном пространстве. Пользователь может создать семейную группу, пригласить членов семьи, вести общий бюджет, планировать события, отслеживать продукты и содержимое дома, хранить информацию о доме и общаться в общем чате.

Таким образом, семье не приходится использовать несколько отдельных сервисов для решения повседневных задач. Все основные данные доступны участникам семейной группы в одном приложении.

**Соответствует ли продукт первоначальной концепции и гипотезам ЦА?**

Да, MVP соответствует первоначальной концепции семейного цифрового пространства. Основные функции ориентированы на совместное использование информации несколькими членами семьи.

Главная гипотеза заключается в том, что пользователи готовы объединять членов семьи в одном цифровом пространстве и использовать его для решения повседневных семейных задач.

## Шаг 2. Аудит функциональности и юзабилити

### Таблица функций текущего MVP

| Функция                             | Категория | Какой шаг сценария обеспечивает | Вклад в ценность                              | Проблемы / Замечания                      |
| ----------------------------------- | --------- | ------------------------------- | --------------------------------------------- | ----------------------------------------- |
| Регистрация и авторизация           | Core      | Вход пользователя               | Предоставляет доступ к семейному пространству | Зависимость от системы авторизации        |
| Создание семейной группы            | Core      | Создание семейного пространства | Объединяет членов семьи                       | Нет проблем                               |
| Приглашение членов семьи            | Core      | Формирование семейной группы    | Позволяет использовать общие данные           | Зависимость от системы приглашений        |
| Добавление доходов и расходов       | Core      | Управление бюджетом             | Позволяет вести общий семейный бюджет         | Необходимо обеспечить корректный пересчёт |
| Создание событий в календаре        | Core      | Планирование семейных дел       | Помогает организовать совместные дела         | Необходимо учитывать права доступа        |
| Добавление и отслеживание продуктов | Core      | Управление продуктами           | Позволяет контролировать содержимое дома      | Необходимо обеспечить синхронизацию       |
| Управление информацией о доме       | Core      | Управление домом и инвентарём   | Хранит бытовую информацию в одном месте       | Модель данных может быть упрощена         |
| Общий семейный чат                  | Core      | Общение членов семьи            | Позволяет общаться без отдельного сервиса     | Зависимость от real-time обновлений       |
| Профили и аватарки членов семьи     | Support   | Просмотр участников             | Помогают различать членов семьи               | Не критично для основной ценности         |

### Анализ

**Какие фичи можно убрать без потери основной ценности?**

- Аватарки и расширенное оформление профилей — не влияют на работу основных семейных сценариев.
- Расширенные настройки уведомлений — для MVP достаточно базовой системы уведомлений.
- Расширенную геолокацию можно временно упростить, если она увеличивает сложность разработки.

**Какие фичи нужно добавить, если без них ключевой сценарий «ломается»?**

- Обработка ошибок регистрации и авторизации.
- Обработка ошибок создания и присоединения к семейной группе.
- Понятное отображение прав доступа пользователей.
- Индикаторы загрузки при сохранении и обновлении данных.
- Подтверждение успешного добавления, изменения или удаления данных.

## Шаг 3. Корректировка функциональности

### Убрать / перенести в Later

| Функция                                   | Решение           | Обоснование                                                            |
| ----------------------------------------- | ----------------- | ---------------------------------------------------------------------- |
| Расширенные профили и аватарки            | Перенести в Later | Не влияют на проверку основной ценности продукта                       |
| Расширенные настройки уведомлений         | Перенести в Later | Для MVP достаточно базовых уведомлений                                 |
| Расширенная геолокация                    | Перенести в Later | Требует дополнительной разработки и разрешений пользователя            |
| Расширенные возможности управления домами | Перенести в Later | Базовой информации о доме и инвентаре достаточно для проверки гипотезы |
| Интеллектуальные рекомендации             | Перенести в Later | Не являются необходимыми для основной работы семейного пространства    |

### Упростить

| Функция         | Упрощение                                                              | Обоснование                                              |
| --------------- | ---------------------------------------------------------------------- | -------------------------------------------------------- |
| Семейный бюджет | Реализовать добавление доходов и расходов и отображение общего баланса | Этого достаточно для проверки ценности общего бюджета    |
| Календарь       | Реализовать создание событий с названием, датой и временем             | Расширенные настройки не нужны для MVP                   |
| Продукты        | Использовать поля: название, количество, категория, срок годности      | Позволяет проверить основной сценарий без сложного учёта |
| Дом и инвентарь | Использовать список объектов с названием и описанием                   | Упрощает разработку и проверку востребованности          |
| Уведомления     | Оставить только базовые уведомления о важных изменениях                | Позволяет проверить пользу функции без сложной настройки |

### Добавить в Core

| Функция                      | Обоснование                                                               |
| ---------------------------- | ------------------------------------------------------------------------- |
| Обработка ошибок авторизации | Пользователь должен понимать причину невозможности войти в систему        |
| Обработка ошибок приглашения | Необходима для корректного присоединения членов семьи                     |
| Индикаторы загрузки          | Пользователь должен понимать, что данные загружаются или сохраняются      |
| Подтверждение действий       | Пользователь должен видеть, что данные успешно добавлены или изменены     |
| Проверка прав доступа        | Необходимо ограничивать доступ к функциям в соответствии с типом аккаунта |

## Шаг 4. Гипотетическая проверка метрик и воронки

**NSM:** Количество активных семейных групп с двумя и более участниками, использующих хотя бы одну общую функцию.

### Воронка взаимодействия

| Шаг воронки | Действие пользователя                                    |
| ----------- | -------------------------------------------------------- |
| 1           | Открытие приложения                                      |
| 2           | Регистрация пользователя                                 |
| 3           | Вход в систему                                           |
| 4           | Создание семейной группы                                 |
| 5           | Приглашение члена семьи                                  |
| 6           | Присоединение участника к группе                         |
| 7           | Добавление общей информации: расход, событие или продукт |
| 8           | Просмотр или изменение общих данных                      |

### Таблица метрик

| Метрика                                   | Зачем нужна                                       | Как измеряем                                                                       |
| ----------------------------------------- | ------------------------------------------------- | ---------------------------------------------------------------------------------- |
| % зарегистрированных пользователей        | Оценить интерес к продукту                        | Количество зарегистрированных / количество посетителей                             |
| % создавших семейную группу               | Проверить ценность семейного пространства         | Количество созданных групп / количество зарегистрированных пользователей           |
| % пригласивших хотя бы одного члена семьи | Оценить готовность использовать продукт совместно | Количество пользователей с отправленным приглашением / количество создавших группу |
| % присоединившихся участников             | Оценить эффективность механизма приглашений       | Количество принятых приглашений / количество отправленных приглашений              |
| Среднее количество участников в группе    | Оценить масштаб использования                     | Количество участников / количество активных семей                                  |
| Количество финансовых операций            | Оценить использование бюджета                     | Количество добавленных доходов и расходов                                          |
| Количество созданных событий              | Оценить использование календаря                   | Количество созданных событий                                                       |
| Количество добавленных продуктов          | Оценить использование домашнего учёта             | Количество добавленных продуктов                                                   |
| Количество сообщений в чате               | Оценить активность общения                        | Количество отправленных сообщений                                                  |

### Ответы на вопросы

**Какие ключевые метрики стоило бы отслеживать?**

В первую очередь необходимо отслеживать количество зарегистрированных пользователей, долю пользователей, создавших семейную группу, долю пользователей, пригласивших членов семьи, количество присоединившихся участников и количество активных семейных групп.

Дополнительно необходимо отслеживать использование основных функций: количество финансовых операций, событий календаря, добавленных продуктов и сообщений в семейном чате.

**Как можно было бы проверить вовлечённость пользователей?**

Вовлечённость можно оценивать по повторным посещениям семейного пространства, количеству действий внутри группы и частоте использования основных функций.

Также важным показателем является количество активных семейных групп, в которых регулярно несколько участников добавляют или изменяют общие данные.

## **Как бы выглядела воронка взаимодействия?**

Регистрация → вход → создание семейной группы → приглашение членов семьи → присоединение участников → добавление общих данных → регулярное использование семейного пространства.

## Шаг 5. Подготовка к реальному тестированию (гипотетическое моделирование)

### План пилота

| Параметр             | Значение                                                                                                                                                                                                                                                                     |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Кого тестируем**   | 5–10 семей или небольших домохозяйств из личного окружения                                                                                                                                                                                                                   |
| **Формат**           | Доступ к MVP по публичной ссылке + короткий опрос после использования                                                                                                                                                                                                        |
| **Сценарий теста**   | 1. Зарегистрироваться<br>2. Создать семейную группу<br>3. Пригласить членов семьи<br>4. Присоединиться к семейной группе<br>5. Добавить расход или доход<br>6. Создать событие<br>7. Добавить продукт<br>8. Отправить сообщение в чате                                       |
| **Вопросы**          | 1. Что было непонятно?<br>2. Удалось ли создать семейную группу?<br>3. Удалось ли пригласить членов семьи?<br>4. Какие функции использовались чаще всего?<br>5. Возникали ли технические проблемы?<br>6. Будете ли использовать сервис снова?<br>7. Что необходимо улучшить? |
| **Критерии успеха**  | 70% зарегистрированных пользователей создают семейную группу, 50% созданных групп приглашают хотя бы одного участника                                                                                                                                                        |
| **Критерии провала** | Менее 50% пользователей создают семейную группу, менее 20% созданных групп приглашают хотя бы одного участника                                                                                                                                                               |

### Ответы на вопросы

**Какие шаги нужно предпринять для реального тестирования?**

1. Развернуть MVP на публичном сервере.
2. Найти 5–10 семей или домохозяйств для тестирования.
3. Предоставить пользователям доступ к приложению.
4. Попросить создать семейную группу и пригласить других участников.
5. Попросить протестировать основные функции: бюджет, календарь, продукты, дом и чат.
6. Собрать количественные метрики использования.
7. Провести короткий опрос после тестирования.
8. Проанализировать результаты и определить функции, требующие доработки.

**Как бы выглядел процесс сбора обратной связи?**

1. Автоматический сбор событий: регистрация, создание семьи, приглашение, добавление расходов, событий, продуктов и сообщений.
2. Опрос пользователей после завершения тестового периода.
3. Короткое интервью с несколькими участниками семейных групп.
4. Фиксация технических проблем и непонятных элементов интерфейса.
5. Анализ наиболее часто используемых функций.
6. Сравнение полученных показателей с критериями успеха.
7. Определение функций, которые необходимо доработать, упростить или перенести в Later.
