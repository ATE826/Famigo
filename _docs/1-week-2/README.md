### 1. Идея, проблема, сценарий

#### Идея продукта

**Famigo** — веб-приложение, создающее единое цифровое пространство для организации семейной жизни.

Сервис объединяет основные инструменты, которые необходимы семье в повседневной жизни:

- управление семейной группой;
- общий семейный бюджет;
- общий календарь;
- список покупок и продуктов;
- управление домом и его содержимым;
- просмотр местоположения членов семьи;
- семейные чаты;
- уведомления.

Главная особенность Famigo заключается в том, что перечисленные функции связаны между собой и работают как единая система.

Например:

> Покупка продуктов → список покупок → продукты в доме → расход → семейный бюджет.

Или:

> Событие → участники → место → напоминание → уведомление → чат.

В Famigo предусмотрено **два вида пользователей: обычный и премиум**.

**Обычный пользователь** получает доступ к основным возможностям сервиса, однако имеет следующие ограничения:

- отсутствует возможность просматривать местоположение членов семьи;
- отсутствует возможность создавать события в общем календаре;
- количество членов семьи ограничено **4 пользователями**;
- отсутствует доступ к некоторым расширенным функциям премиум-подписки.

**Премиум-пользователь** получает доступ к расширенному функционалу, включая просмотр местоположения членов семьи, создание событий в общем календаре, увеличение допустимого количества участников семьи и другие дополнительные возможности.

В последующих обновлениях для премиум-пользователей планируется внедрение интеллектуальной функции, которая сможет анализировать продукты, имеющиеся в доме, и предлагать подходящие рецепты.

#### Проблема

Семейная жизнь связана с большим количеством повседневных задач: планированием дел, ведением бюджета, покупками, организацией домашних дел, общением и контролем местоположения членов семьи.

Для решения этих задач люди используют большое количество различных приложений: мессенджеры, банковские приложения, календари, карты, списки покупок и заметки.

В результате информация оказывается разбросана по разным сервисам. Пользователю приходится постоянно переключаться между приложениями, а члены семьи не имеют единого пространства для совместного управления повседневными задачами.

Особенно проблема проявляется в семьях с детьми, где количество расходов, событий, покупок и домашних задач значительно увеличивается.

#### Сценарий

- **Пользователь:** семья, пара или совместно проживающие люди.
- **Ситуация:** несколько членов семьи ежедневно решают общие задачи: планируют события, совершают покупки, контролируют расходы, распределяют домашние дела и поддерживают связь.
- **Проблема:** информация находится в разных приложениях, поэтому участникам приходится самостоятельно синхронизировать данные между собой.
- **Последствия:** забытые задачи и покупки, потеря информации, сложности с контролем семейных расходов, необходимость постоянно писать сообщения друг другу и переключаться между несколькими приложениями.
- **Решение:** Famigo объединяет основные семейные процессы в одном цифровом пространстве.

Таким образом, основная конкурентная среда Famigo состоит из двух групп. Прямые конкуренты объединяют несколько семейных функций, однако обычно делают акцент только на отдельных направлениях. Косвенные конкуренты эффективно закрывают отдельные потребности — финансы, общение, покупки или геолокацию, но требуют использования нескольких разных сервисов.

Главное конкурентное преимущество Famigo — **объединение этих функций в одном семейном пространстве и взаимосвязь между ними**.

# Драйверы

1. Люди используют всё больше цифровых сервисов для решения повседневных задач, однако семейная информация по-прежнему часто распределена между разными приложениями. Это формирует потребность в едином пространстве для совместного управления.

2. Распространение семейных и совместных финансовых инструментов показывает востребованность решений, позволяющих нескольким людям управлять общими расходами.

3. Семьи регулярно используют общие чаты, календари и списки покупок. Объединение этих привычных сценариев в одном сервисе может снизить количество переключений между приложениями.

4. Развитие искусственного интеллекта создаёт возможности для добавления интеллектуальных функций. В дальнейшем Famigo сможет использовать нейросеть для анализа продуктов, находящихся дома, и предложения подходящих рецептов премиум-пользователям.

---

# Барьеры

1. **Высокая конкуренция со стороны уже используемых приложений.** Пользователю проще продолжать пользоваться Telegram, банковским приложением, календарём и заметками, чем переходить на новый сервис.

2. **Необходимость привлечения нескольких пользователей.** Ценность Famigo значительно возрастает, когда в сервис подключена вся семья. Если зарегистрировался только один человек, часть возможностей продукта становится менее полезной.

3. **Формирование привычки.** Пользователю необходимо регулярно возвращаться в приложение для планирования, контроля расходов, покупок и домашних задач.

4. **Недоверие к функциям геолокации.** Возможность видеть местоположение членов семьи связана с вопросами приватности, поэтому пользователь должен самостоятельно контролировать, кому доступна эта информация.

5. **Сложность монетизации.** Пользователь может считать семейный органайзер базовой функцией, которую не обязательно оплачивать. Поэтому премиум-функции должны давать заметную дополнительную ценность.

---

# Ценность

Для семьи или пары, которым необходимо совместно организовывать повседневную жизнь, Famigo предоставляет единое пространство для управления расходами, покупками, событиями, домом, местоположением и общением, снижая необходимость использовать несколько разных приложений.

**Снижение количества переключений между сервисами** — основные семейные процессы находятся в одном приложении.

**Снижение количества забытых задач** — события, покупки и уведомления хранятся в единой системе.

**Упрощение управления семейным бюджетом** — расходы и покупки могут быть связаны между собой.

**Упрощение бытовой организации** — семья получает единый список продуктов и содержимого дома.

**Улучшение коммуникации** — общение и информация о семейных задачах находятся в одном пространстве.

**Дополнительная ценность премиум-версии** — доступ к геолокации, расширенному календарю, увеличенному количеству участников и будущим интеллектуальным функциям.

# Почему это реалистично

Основные функции Famigo основаны на уже существующих и хорошо известных пользователям сценариях: чаты, календари, списки покупок, банковские операции, карты и уведомления.

Вместо создания принципиально нового поведения пользователя продукт объединяет уже привычные действия в одном интерфейсе.

Технически MVP может быть реализован как веб-приложение с использованием современных веб-технологий. Основные функции не требуют сложных технологий и могут быть реализованы поэтапно.

На первом этапе возможно реализовать:

- регистрацию и авторизацию;
- создание семейной группы;
- общий бюджет;
- календарь;
- список покупок;
- управление домом;
- семейный чат.

После проверки востребованности продукта можно расширить функциональность геолокацией, премиум-подпиской и интеллектуальными функциями.

Freemium-модель также снижает барьер входа: пользователь может начать пользоваться сервисом бесплатно, а перейти на премиум после возникновения потребности в расширенных возможностях.

# Формулировка гипотезы

**Молодые семьи и пары готовы использовать единый сервис для управления семейными задачами, если он позволяет объединить бюджет, календарь, покупки, дом и общение без необходимости использовать несколько приложений.**

# Как проверить

Создать прототип Famigo с основными функциями: семейная группа, бюджет, календарь, список покупок и управление домом.

Провести тестирование с 20–30 пользователями из целевого сегмента. Предложить им использовать прототип в течение одной-двух недель, после чего провести опрос и интервью.

# Какие данные нужны

- количество пользователей, начавших пользоваться прототипом;
- количество созданных семей;
- количество приглашённых членов семьи;
- частота использования отдельных функций;
- количество созданных событий;
- количество добавленных покупок;
- количество финансовых операций;
- результаты пользовательского опроса;
- количество пользователей, которые готовы продолжить использование сервиса.

# Критерий подтверждения

Не менее **60% пользователей** продолжают пользоваться сервисом после первой недели.

Не менее **50% зарегистрированных пользователей** приглашают хотя бы одного члена семьи.

Не менее **60% участников тестирования** считают удобным наличие основных семейных функций в одном приложении.

# Критерий опровержения

Большинство пользователей используют только одну функцию и не видят необходимости в едином сервисе.

Более половины участников предпочитают продолжать использовать привычные приложения вместо Famigo.

Менее **30% пользователей** готовы продолжить использование сервиса после тестового периода.

# Формулировка гипотезы

**Премиум-подписка будет востребована пользователями, если платные функции решают реальные семейные задачи и дают заметную дополнительную ценность по сравнению с бесплатной версией.**

# Как проверить

Предоставить пользователям бесплатную версию с ограничением количества членов семьи до 4 человек и без возможности просмотра местоположения и создания событий в общем календаре.

Предложить премиум-версию с расширенными возможностями и измерить готовность пользователей перейти на платный тариф.

# Какие данные нужны

- количество пользователей бесплатной версии;
- количество пользователей, ознакомившихся с премиум-функциями;
- количество переходов на страницу подписки;
- количество пользователей, оформивших подписку;
- причины отказа от покупки;
- наиболее востребованные премиум-функции.

# Критерий подтверждения

Не менее **5–10% активных пользователей** готовы оформить премиум-подписку.

Наиболее востребованными функциями являются геолокация, расширенный календарь и увеличение количества членов семьи.

# Критерий опровержения

Менее **2% активных пользователей** готовы платить за премиум.

Большинство пользователей не считают ограничения бесплатной версии существенными и не видят необходимости переходить на платную подписку.

# Формулировка гипотезы

**Функция интеллектуального подбора рецептов на основе продуктов, имеющихся в доме, повысит ценность премиум-подписки.**

# Как проверить

После реализации функции предоставить её группе премиум-пользователей и сравнить частоту использования сервиса и готовность продлевать подписку с пользователями, которые не получили доступ к функции.

Также провести опрос пользователей о полезности предложенных рецептов.

# Какие данные нужны

- количество пользователей, использующих функцию;
- количество сгенерированных рекомендаций;
- количество открытых рецептов;
- оценка полезности рекомендаций;
- количество повторных обращений к функции;
- влияние функции на продление премиум-подписки.

# Критерий подтверждения

Не менее **30% премиум-пользователей** используют функцию хотя бы один раз в месяц.

Не менее **60% пользователей**, попробовавших функцию, оценивают её как полезную.

Пользователи отмечают функцию как одну из причин продолжения использования премиум-версии.

# Критерий опровержения

Большинство пользователей не используют функцию после первого знакомства.

Менее **30% пользователей** считают рекомендации полезными.

Функция не оказывает заметного влияния на желание пользователей продлевать премиум-подписку.
