# Шаг 1. Определение стадии проекта и «инвестируемого риска»

## Стадия проекта

**MVP / подготовка к первым пользовательским тестам (Pre-seed)**

Famigo находится на стадии разработки и проверки MVP.

Основная задача текущего этапа — подтвердить, что семьи готовы:

- создавать общее семейное пространство;
- приглашать других членов семьи;
- совместно использовать бюджет;
- использовать общий календарь;
- вести учёт продуктов;
- хранить информацию о доме;
- общаться внутри семейного чата;
- регулярно возвращаться в приложение.

---

## Что уже подтверждено (сигналы)

### MVP

Определено ядро MVP Famigo.

В Core входят:

### Пользовательское тестирование

- Определён план тестирования MVP на **5–10 семьях или небольших домохозяйствах**.
- Подготовлен основной пользовательский сценарий:
  1. регистрация;
  2. создание семейной группы;
  3. приглашение участника;
  4. добавление расхода;
  5. создание события;
  6. добавление продукта;
  7. добавление информации о доме;
  8. отправка сообщения в семейном чате.

- Определены критерии успешного прохождения MVP:
  - ≥70% зарегистрированных пользователей создают семейную группу;
  - ≥50% созданных семей приглашают хотя бы одного участника.

- Подготовлен список вопросов для сбора обратной связи после тестирования.

---

### Монетизация

- Определена основная модель монетизации: **Freemium + Premium-подписка**.
- Стоимость Premium: **249 ₽/мес**.
- Подписка привязывается к одной семейной группе.
- Один участник оплачивает Premium, после чего расширенные возможности доступны всей семье.
- Основные функции остаются бесплатными, чтобы снизить барьер входа.
- Premium включает расширенные возможности бюджета, истории, уведомлений, управления домами и другие дополнительные функции.

---

### Рост

Определено основное ядро роста:

> **регистрация → создание семьи → приглашение участников → использование функций → повторное использование → Premium**

Подготовлены основные метрики:

- Activation Rate;
- Family Invitation Rate;
- Retention Rate;
- Premium Conversion;
- MRR;
- Churn Rate;
- ARPU.

---

### Финансовая модель

- Разработана финансовая модель на 12 месяцев.
- Рассмотрены три сценария:
  - консервативный;
  - базовый;
  - оптимистичный.

- Базовая цена Premium — **249 ₽/мес**.
- В базовом сценарии к 12 месяцу планируется около **320 платящих семей**.
- MRR в базовом сценарии составляет около **79 680 ₽**.
- При расходах около **35 000 ₽/мес** операционный результат составляет около **+44 680 ₽/мес**.
- Выход на операционную безубыточность ожидается примерно на **10 месяце**.

### Ценность

Сформулировано основное ценностное предложение:

> **Famigo — всё важное для семьи в одном месте.**

Основная проблема заключается в том, что семейные данные распределены между разными сервисами:

- расходы — в банковских приложениях или таблицах;
- события — в календарях;
- продукты — в заметках;
- бытовая информация — отдельно;
- общение — в мессенджерах.

Famigo объединяет эти процессы внутри одного семейного цифрового пространства.

# Шаг 4. Инвестиционная история (Investment Thesis)

**Famigo — это B2C-веб-приложение для организации семейной жизни в одном общем цифровом пространстве.**

Вместо использования отдельных приложений для бюджета, календаря, продуктов, бытовой информации и общения семья получает одно связанное пространство.

Основная идея:

> **Famigo — всё важное для семьи в одном месте.**

---

## Почему проблема существенна?

Сегодня информация о семейной жизни часто распределена между несколькими сервисами.

Например:

- расходы находятся в банковских приложениях или таблицах;
- события — в календарях;
- покупки и продукты — в заметках;
- бытовая информация — в отдельных списках;
- общение — в мессенджерах.

В результате семье приходится постоянно переключаться между сервисами, а актуальная информация не всегда доступна всем участникам.

Famigo решает эту проблему через единое семейное пространство.

---

## Почему наше решение?

Famigo объединяет основные семейные сценарии:

- 👨‍👩‍👧 управление семейной группой;
- 🏠 дома и семейные пространства;
- 💰 семейный бюджет;
- 🧊 продукты;
- 📅 календарь;
- 💬 семейный чат;
- 🔔 уведомления;
- ⚙️ управление участниками и настройками.

Ключевое отличие Famigo — функции не существуют отдельно друг от друга.

Например:

> Дом → Продукты → Расход → Семейный бюджет

или:

> Член семьи → Календарь → Событие → Уведомление → Семейный чат

За счёт этого Famigo становится не набором отдельных инструментов, а единой системой организации семейной жизни.

---

## Почему MVP реалистичен?

Первая версия не включает всю полную концепцию продукта.

MVP сфокусирован только на основных сценариях:

1. создание семейной группы;
2. приглашение участников;
3. семейный бюджет;
4. общий календарь;
5. учёт продуктов;
6. управление домом;
7. семейный чат;
8. профиль и просмотр участников.

Более сложные функции переносятся в следующие версии.

В Later остаются:

- real-time геолокация;
- расширенные уведомления;
- нейросетевая функция подбора рецептов;
- интеллектуальные рекомендации;
- расширенная аналитика;
- расширенная история активности;
- семейная галерея;
- дополнительные возможности управления домами.

Это позволяет сначала проверить основную ценность продукта и только после этого увеличивать сложность.

---

## Почему сейчас?

Пользователи уже привыкли использовать цифровые сервисы для отдельных бытовых задач: банковские приложения, календари, заметки, мессенджеры и сервисы планирования.

Famigo использует уже существующее пользовательское поведение, но объединяет несколько регулярных сценариев внутри одного продукта.

Рост количества цифровых сервисов одновременно создаёт проблему фрагментации, которую Famigo пытается решить.

---

## Почему бизнес-модель масштабируема?

Основная модель — **Freemium + Premium-подписка**.

Базовые функции доступны бесплатно.

Premium стоит:

> **249 ₽/мес на одну семейную группу.**

Оплата распространяется на всю семью, а не на одного пользователя.

Основные преимущества модели:

- регулярная подписочная выручка;
- низкий барьер входа;
- возможность органического роста;
- один пользователь приглашает нескольких членов семьи;
- относительно низкие дополнительные расходы на каждого нового пользователя;
- возможность развития дополнительных Premium-функций.

---

## Почему проект может расти органически?

В Famigo встроен естественный механизм приглашений.

Первый пользователь:

> регистрируется → создаёт семейную группу → приглашает родственников.

Таким образом, для полноценного использования продукта пользователю необходимо самостоятельно приглашать других участников.

Это создаёт возможность встроенного органического роста.

# Итог

Famigo находится на стадии **Pre-seed / MVP**.

Основной «инвестируемый риск» проекта заключается не в технической возможности создать приложение, а в подтверждении пользовательского поведения:

> **будут ли семьи действительно использовать единое цифровое пространство совместно и регулярно.**

На ближайшем этапе необходимо подтвердить четыре ключевые гипотезы:

1. **Пользователь готов создать семейную группу.**
2. **Он готов пригласить других членов семьи.**
3. **Несколько участников готовы регулярно использовать общие функции.**
4. **Часть активных семей готова платить 249 ₽/мес за Premium.**

Если эти гипотезы подтверждаются, Famigo получает основу для масштабирования B2C-подписочной модели.

Главная инвестиционная логика проекта:

> **Инвестиции → завершение MVP → первые семьи → подтверждение retention → подтверждение Premium-конверсии → масштабирование.**

Таким образом, Famigo позиционируется как потенциальная единая цифровая инфраструктура для повседневной семейной жизни.
