## 1. Что такое Famigo

**Famigo** — это веб-приложение для организации семейной жизни в одном общем цифровом пространстве.

Главная идея:

> **Famigo — всё важное для семьи в одном месте.**

Сервис объединяет:

- 👨‍👩‍👧 членов семьи;
- 🏠 дома и семейные пространства;
- 💰 общий бюджет;
- 🧊 продукты и холодильники;
- 📅 семейный календарь;
- 🗺️ местоположение и карту;
- 💬 семейные чаты;
- 🔔 уведомления;
- ⚙️ настройки и управление семьёй.

При этом это не просто набор отдельных функций. Все разделы связаны между собой.

Например:

> Дом → Холодильник → Продукты → Расход → Бюджет

или:

> Член семьи → Календарь → Событие → Уведомление → Чат

# 2. Главная концепция

Famigo представляет семью как **единое цифровое пространство**.

У пользователя есть аккаунт.

Аккаунт состоит в одной или нескольких семейных группах.

# 25. Визуальный принцип

Не нужно делать:

> бюджет — зелёная страница
> календарь — оранжевая
> карта — синяя
> семья — розовая

**Все страницы используют одну палитру.**

Меняется только содержание.

Главное соотношение:

```text
Warm White
████████████████████

White
█████

Deep Green
███

Soft Orange
█
```

То есть интерфейс в основном нейтральный, **Green отвечает за взаимодействие**, а **Orange добавляет эмоциональные акценты**.

# 29. MVP

Я бы **не пытался сделать всё сразу**.

Первая версия Famigo:

```text
AUTH
  ↓
FAMILY
  ↓
DASHBOARD
  ├── HOMES
  ├── BUDGET
  ├── CALENDAR
  └── FAMILY
```

То есть MVP:

1. регистрация/авторизация;
2. создание семьи;
3. приглашение участников;
4. Dashboard;
5. дома;
6. семейный бюджет;
7. календарь;
8. профиль.

А затем:

```text
V2
├── Холодильник
├── Карта
├── Чаты
└── Уведомления
```

И уже потом:

```text
V3
├── WebSocket
├── real-time location
├── push notifications
├── расширенная аналитика
├── recurring events
├── финансовые цели
└── автоматизация
```

### Главная идея Famigo в одном предложении:

> **Famigo — это единое цифровое пространство, которое объединяет людей, дома и повседневную жизнь одной семьи.**

И за счёт этого проект одновременно выглядит как **реальный веб-продукт**, а не просто учебный CRUD, и даёт тебе достаточно возможностей отработать полноценный **React + TypeScript + Node.js + PostgreSQL Fullstack**.

### Основные языки:

**JavaScript** — frontend и backend
**SQL** — работа с базой данных PostgreSQL
Технологии
**React** — frontend
**Node.js** — серверная среда
**Express.js** — backend/API
**PostgreSQL** — база данных
