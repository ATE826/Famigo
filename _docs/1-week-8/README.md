# Создание MVP

## Шаг 1. Уточнение цели MVP и метрики успеха

**Сегмент:** Семьи и совместно проживающие люди — семьи из 2–6 человек, которым необходимо совместно организовывать бытовые, финансовые и повседневные вопросы.

**Ценность:** Возможность объединить семейный бюджет, календарь, информацию о доме, продукты и семейное общение в одном цифровом пространстве, чтобы не использовать несколько отдельных сервисов.

**Целевое действие на MVP:** Создание семейной группы и совместное использование основных функций семейного пространства.

**Метрики проверки:**

- Доля зарегистрированных пользователей, создавших или присоединившихся к семейной группе — **цель: не менее 60%**.
- Доля созданных семей, в которых было выполнено хотя бы одно совместное действие другим участником — **цель: не менее 40%**.
- Доля семей, использовавших хотя бы две основные функции MVP — **цель: не менее 50%**.

На MVP мы проверяем, что представители целевого сегмента готовы создать семейное пространство и использовать его для совместного управления повседневными делами: бюджетом, календарём, домом и продуктами. Успех MVP определяется не только созданием аккаунта, но и фактическим совместным использованием сервиса несколькими членами семьи.

## Шаг 2. Основной user flow

| Шаг | Действие                                                                                                                |
| --- | ----------------------------------------------------------------------------------------------------------------------- |
| 1   | Пользователь открывает Famigo и переходит на страницу регистрации.                                                      |
| 2   | Пользователь создаёт аккаунт, указывая имя, email и пароль.                                                             |
| 3   | После регистрации пользователь создаёт семейную группу и указывает её название.                                         |
| 4   | Пользователь автоматически становится участником созданной семейной группы.                                             |
| 5   | Пользователь приглашает других членов семьи в группу.                                                                   |
| 6   | Приглашённый пользователь регистрируется или входит в существующий аккаунт и присоединяется к семейной группе.          |
| 7   | Пользователь открывает семейное пространство и получает доступ к основным разделам: бюджет, календарь, дома и продукты. |
| 8   | Член семьи добавляет доход или расход в общий бюджет.                                                                   |
| 9   | Член семьи создаёт событие в общем календаре.                                                                           |
| 10  | Член семьи создаёт дом и добавляет информацию о доме и его содержимом.                                                  |
| 11  | Член семьи добавляет продукты и отслеживает их состояние.                                                               |
| 12  | Участники видят изменения и могут взаимодействовать с общими данными семейного пространства.                            |
| 13  | Члены семьи используют общий чат для обсуждения бытовых и семейных вопросов.                                            |
| 14  | Пользователь просматривает свой профиль и список участников семьи.                                                      |

## Шаг 3. Альтернативный сценарий

| Шаг | Действие                                                                      |
| --- | ----------------------------------------------------------------------------- |
| 1   | Пользователь пытается войти в Famigo или зарегистрироваться.                  |
| 2   | Система обнаруживает некорректные данные, например неверный email или пароль. |
| 3   | Система показывает понятное сообщение об ошибке.                              |
| 4   | Пользователь исправляет введённые данные.                                     |
| 5   | Система повторно проверяет данные.                                            |
| 6   | Авторизация или регистрация проходит успешно.                                 |
| 7   | Пользователь переходит в семейное пространство или создаёт семейную группу.   |

### Альтернативный сценарий приглашения

| Шаг | Действие                                                                              |
| --- | ------------------------------------------------------------------------------------- |
| 1   | Пользователь получает приглашение в семейную группу.                                  |
| 2   | Пользователь открывает приглашение.                                                   |
| 3   | Система проверяет действительность приглашения.                                       |
| 4   | Если приглашение действительно, пользователь присоединяется к семейной группе.        |
| 5   | Если приглашение недействительно или истекло, система показывает сообщение об ошибке. |
| 6   | Пользователь может запросить новое приглашение.                                       |

| **Бюджет**                 | Управление семейными финансами | Доходы, расходы, баланс, категории, история                              | Загрузка, пусто, ошибка, успех           | Добавление операции, история           |
| **Календарь**              | Планирование семейных дел      | Календарь, события, кнопка создания                                      | Загрузка, пусто, ошибка, успех           | Создание события                       |
| **Чат**                    | Семейное общение               | Сообщения, автор, время, поле ввода                                      | Загрузка, пусто, ошибка, новое сообщение | Семейное пространство                  |
| **Профиль**                | Управление личной информацией  | Имя, email, аватар, настройки профиля                                    | Загрузка, ошибка, успех                  | Настройки                              |
| **Страница ошибки**        | Обработка ошибок               | Сообщение, кнопка повторной попытки/возврата                             | Ошибка                                   | Главная страница                       |

## Шаг 5. Модель данных / сущностей

| Сущность                | Поля                                                                                          | Связи                                                               |
| ----------------------- | --------------------------------------------------------------------------------------------- | ------------------------------------------------------------------- |
| **Пользователь**        | ID, имя, email, пароль, аватар, дата создания                                                 | Может состоять в одной или нескольких семейных группах              |
| **Семья**               | ID, название, дата создания                                                                   | Имеет участников, дома, финансовые операции, события и чат          |
| **Участник семьи**      | ID семьи, ID пользователя, роль, тип аккаунта                                                 | Связывает пользователя и семейную группу                            |
| **Приглашение**         | ID, ID семьи, email/ID приглашённого пользователя, роль, статус, дата создания, срок действия | Принадлежит семейной группе                                         |
| **Дом**                 | ID, ID семьи, название, адрес, описание, изображение, дата создания                           | Принадлежит семейной группе, содержит продукты и бытовую информацию |
| **Продукт**             | ID, ID дома, название, категория, количество, срок годности, статус                           | Принадлежит дому                                                    |
| **Инвентарь**           | ID, ID дома, название, категория, количество, описание, статус                                | Принадлежит дому                                                    |
| **Финансовая операция** | ID, ID семьи, ID пользователя, ID дома, тип, сумма, категория, описание, дата создания        | Принадлежит семье и может быть связана с домом                      |
| **Событие**             | ID, ID семьи, ID создателя, название, описание, дата, время начала, время окончания, место    | Принадлежит семейной группе                                         |
| **Участник события**    | ID события, ID пользователя                                                                   | Связывает пользователей и события                                   |
| **Чат**                 | ID, ID семьи, дата создания                                                                   | Принадлежит семейной группе                                         |
| **Сообщение**           | ID, ID чата, ID пользователя, текст, дата создания                                            | Принадлежит чату и пользователю                                     |
| **Уведомление**         | ID, ID пользователя, тип, заголовок, текст, статус прочтения, дата создания                   | Принадлежит пользователю                                            |

## Шаг 7. Definition of Done для MVP

| №      | Критерий                                                                                                   |
| ------ | ---------------------------------------------------------------------------------------------------------- |
| **1**  | Реализованы все **Must** user stories MVP.                                                                 |
| **2**  | Основной user flow от регистрации до использования семейного пространства проходит без критических ошибок. |
| **3**  | Реализована регистрация и авторизация пользователей.                                                       |
| **4**  | Пользователь может создать семейную группу и пригласить других участников.                                 |
| **5**  | Реализованы основные функции семейного пространства: бюджет, календарь, дома и продукты.                   |
| **6**  | Пользователь может взаимодействовать с другими членами семьи через общий чат.                              |
| **7**  | Данные разных семейных групп изолированы друг от друга.                                                    |
| **8**  | MVP работает на мобильных устройствах и компьютерах.                                                       |
| **9**  | Все критические и блокирующие дефекты исправлены.                                                          |
| **10** | Подготовлен сценарий демонстрации MVP.                                                                     |
| **11** | Оформлена инструкция для пользователя по созданию семьи и приглашению участников.                          |
| **12** | Зафиксированы ограничения MVP и функции, перенесённые на следующие версии.                                 |
| **13** | MVP развёрнут на сервере и доступен по публичной ссылке.                                                   |
| **14** | Настроена базовая аналитика ключевых действий пользователей.                                               |
| **15** | Зафиксированы результаты проверки метрик успеха MVP.                                                       |
