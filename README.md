# Famigo

## Что такое Famigo

**Famigo** — веб-приложение для организации семейной жизни в едином цифровом пространстве.

> Famigo — всё важное для семьи в одном месте.

Сервис объединяет в себе:

- 👨‍👩‍👧 членов семьи;
- 🏠 дома и семейные пространства;
- 💰 общий бюджет;
- 🧊 продукты и холодильники;
- 📅 семейный календарь;
- 🗺️ местоположение и карту;
- 💬 семейные чаты;
- 🔔 уведомления;
- ⚙️ настройки и управление семьёй.

Ключевая особенность — все разделы связаны между собой, а не работают как набор изолированных функций. Например:

```
Дом → Холодильник → Продукты → Расход → Бюджет
```

или

```
Член семьи → Календарь → Событие → Уведомление → Чат
```

Famigo представляет семью как единое цифровое пространство: у пользователя есть аккаунт, который состоит в одной или нескольких семейных группах, а внутри каждой семьи находятся участники, дома, бюджет, календарь, карта, чаты и уведомления.

## MVP

Первая версия Famigo фокусируется на базовом сценарии: регистрация → создание семьи → приглашение участников → повседневное управление бюджетом, домом, продуктами и календарём → общение в чате.

| Функция                             | Категория | Какой шаг сценария обеспечивает | Вклад в ценность                              | Проблемы / Замечания                      |
| ----------------------------------- | --------- | ------------------------------- | --------------------------------------------- | ----------------------------------------- |
| Регистрация и авторизация           | Core      | Вход пользователя               | Предоставляет доступ к семейному пространству | Зависимость от системы авторизации        |
| Создание семейной группы            | Core      | Создание семейного пространства | Объединяет членов семьи                       | Нет проблем                               |
| Приглашение членов семьи            | Core      | Формирование семейной группы    | Позволяет использовать общие данные           | Зависимость от системы приглашений        |
| Добавление доходов и расходов       | Core      | Управление бюджетом             | Позволяет вести общий семейный бюджет         | Необходимо обеспечить корректный пересчёт |
| Создание событий в календаре        | Core      | Планирование семейных дел       | Помогает организовать совместные дела         | Необходимо учитывать права доступа        |
| Добавление и отслеживание продуктов | Core      | Управление продуктами           | Позволяет контролировать содержимое дома      | Необходимо обеспечить синхронизацию       |
| Управление информацией о доме       | Core      | Управление домом и инвентарём   | Хранит бытовую информацию в одном месте       | Модель данных может быть упрощена         |
| Общий семейный чат                  | Core      | Общение членов семьи            | Позволяет общаться без отдельного сервиса     | Зависимость от real-time обновлений       |
| Профили и аватарки членов семьи     | Support   | Просмотр участников             | Помогают различать членов семьи               | Не критично для основной ценности         |

## Разделы приложения

| Раздел              | Роут                                        | Описание                                                                                                |
| ------------------- | ------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| Авторизация         | `/login`, `/register`                       | Вход, регистрация, восстановление пароля, создание семьи или присоединение по приглашению               |
| Dashboard           | `/`                                         | Главный экран: сводка по семье, домам, бюджету, ближайшим событиям, последним действиям                 |
| Семья               | `/family`, `/family/invite`                 | Список участников, роли (Owner/Admin/Member), приглашения по email или ссылке                           |
| Дома                | `/homes`, `/homes/:id`                      | Список семейных пространств, карточка конкретного дома (обзор, холодильник, расходы, задачи, участники) |
| Холодильник         | `/homes/:id/fridge`                         | Учёт продуктов: категории, количество, срок годности                                                    |
| Бюджет              | `/budget`, `/budget/add`, `/budget/history` | Общий семейный бюджет, добавление доходов/расходов, история операций с фильтрами                        |
| Календарь           | `/calendar`, `/calendar/create`             | Общий семейный календарь, создание и управление событиями                                               |
| Карта               | `/map`                                      | Отображение членов семьи, домов и сохранённых мест                                                      |
| Чаты                | `/chats`, `/chats/:id`                      | Семейный чат в реальном времени (WebSocket)                                                             |
| Уведомления         | `/notifications`                            | Единая лента событий: сообщения, бюджет, продукты, приглашения                                          |
| Профиль и настройки | `/profile`, `/settings`                     | Личные данные, тема оформления, безопасность, уведомления                                               |

> Список покупок добавлен в экосистему 07.09.2026 и рассматривается для включения в MVP.

## Дизайн-система

Палитра: **Warm White + Deep Green + Soft Orange**.

- `#F5F3EE` Warm White — основной фон
- `#FFFFFF` White — карточки и поверхности
- `#20221F` Dark — основной текст
- `#73766F` Muted — вторичный текст
- `#667A55` Deep Green — основной акцент (кнопки, активная навигация, ссылки)
- `#E5EBE0` Soft Green — hover, выделение, свои сообщения в чате
- `#D38A62` Soft Orange — уведомления, события, важные индикаторы
- `#F3E2D8` Orange Light — мягкий фон для orange-элементов
- `#E4E4DE` Border — границы и разделители

Принцип: интерфейс в основном нейтральный, зелёный отвечает за взаимодействие, оранжевый — за эмоциональные акценты. Все разделы используют одну палитру — цвет не привязывается к конкретной странице.
